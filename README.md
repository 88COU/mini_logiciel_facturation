# Fadel Digital Electronics — Mini logiciel de facturation

Version adaptée à Fadel Digital Electronics à partir du mini logiciel ElectroMax.

Modules : tableau de bord, nouvelle facture, historique/recherche des factures, clients, catalogue produits, bénéfices et export PDF A4.
